# 리그 제도

**리그가 어떻게 생겼는지를 보면 그 나라 축구의 성격이 보여요.** 스무 팀이 서른여덟 경기를 치르는 게
축구의 기본처럼 느껴지지만, 막상 세어 보면 그런 리그는 오히려 적은 편이에요. 스코틀랜드는 열두 팀이
서른세 경기를 치른 뒤 위아래로 갈라지고, 멕시코는 한 해에 우승팀을 두 번 뽑고, 미국은 강등이 없는 대신
플레이오프로 챔피언을 가려요.

이 문서는 **실제로는 어떤지**를 먼저 적고, 그중 무엇을 게임에 넣었는지를 이어서 적어요.
수치는 최근 시즌 기준이라 해마다 조금씩 바뀌어요. 그대로 베끼려는 게 아니라, **나라마다 다르게 느껴지게**
하는 게 목표예요.

## 처음 엔진은 이랬어요

일곱 갈래를 넣기 전, 엔진은 모든 리그를 똑같이 다뤘어요.

| | |
|---|---|
| 리그당 팀 수 | **20팀 고정** — 실제와 제일 크게 어긋나던 부분이에요 |
| 경기 수 | 더블 라운드로빈 38경기 |
| 승강 | 위아래 **3팀 고정** |
| 우승 | 정규리그 1위 |
| 시즌 | 한 해에 한 번 |

다행히 일정 생성기(`FixtureScheduler.Build`)는 **처음부터 팀 수를 가리지 않았어요.** 홀수면 부전승 자리를 넣고
`n-1` 라운드로 짜 줬거든요. 진행 엔진도 라운드 번호로 돌아서, 라운드 수가 다른 리그가 한 세계에 섞여도 괜찮았어요.

20팀에 묶여 있던 곳은 세 군데뿐이었어요.

1. `WorldGenerator.ClubsPerLeague = 20` — 도시 배분, 리그 생성 루프, 시즌 길이
2. `RepLadder` 세 묶음 — 길이가 20으로 고정된 평판 사다리
3. `league.promotionSpots / relegationSpots` — 전부 3

| 16 | 벨기에 · 러시아 · 우크라이나 · 체코 · 세르비아 · 루마니아 · 스웨덴 · 노르웨이 · 중국 · 이란 · 태국 · 모로코 · 튀니지 · 알제리 · 남아프리카 · 우루과이 · 칠레 · 볼리비아 |
| 18 | 독일 · 프랑스 · 포르투갈 · 네덜란드 · 폴란드 · 멕시코 · 사우디아라비아 · 인도네시아 · 이집트 · 가나 |
| 20 | 잉글랜드 · 스페인 · 이탈리아 · 브라질 · 일본 · 콜롬비아 · 나이지리아 · 튀르키예 |
| 24+ | 미국(29·콘퍼런스) · 아르헨티나(28) |

### 2부가 1부보다 큰 나라

잉글랜드 2·3·4부는 **24팀**이에요(46경기). 스페인 2부는 22팀, 이탈리아 2부는 20팀이고요.
"아래로 내려갈수록 팀이 많아진다"는 것 자체가 피라미드다운 모습이에요.

### 승강 자리

| 자리 | 나라 |
|---|---|
| 4팀 | 브라질 |
| 3팀 | 잉글랜드 · 스페인 · 이탈리아 · 튀르키예 · 일본 · 사우디아라비아 · 태국 |
| 2팀 + 플레이오프 | 독일(1부 16위가 2부 3위와 홈앤드어웨이) |
| 2팀 | 포르투갈 · 네덜란드 · 러시아 · 일본 |
| 1~2팀 | 작은 리그 대부분 |
| **없음** | 미국 · 호주 · 인도 · 멕시코(현행) |

2부에서 올라가는 방식도 나라마다 달라요. 잉글랜드 2부는 **1·2위가 자동 승격하고, 3~6위가 플레이오프**를 치러
한 장을 더 가져가요. 스페인·이탈리아·독일 2부에도 비슷한 플레이오프가 있어요.

## 제도는 크게 일곱 갈래예요

실제 리그를 생김새로 묶어 보면 일곱 가지로 나뉘어요.

### 1. 더블 라운드로빈 (기본)

모든 팀과 홈·원정을 한 번씩 치러요. 잉글랜드·스페인·이탈리아·독일·일본 등 대부분이 이렇게 해요.

### 2. 쿼드러플 라운드로빈

팀이 열 개뿐이라 네 번씩 맞붙어서 36경기를 치러요. **크로아티아 · 아일랜드 · 뉴질랜드**가 그래요.

### 3. 스플릿 (정규리그 뒤 상·하위 분리)

정규리그를 다 치른 뒤 상위권과 하위권으로 갈라서, 각자 자기들끼리 몇 경기를 더 치러요. 우승은 상위 그룹에서만,
강등은 하위 그룹에서만 나와요.

| 나라 | 모양 |
|---|---|
| 스코틀랜드 | 12팀 33경기 → 상6·하6 각 5경기 (38경기) |
| 한국 | 12팀 33경기 → 파이널A·B 각 5경기 |
| 덴마크 | 12팀 22경기 → 챔피언십 6팀 10경기 + 강등권 |
| 오스트리아 · 스위스 | 12팀 → 상·하위 분리, **승점 절반**으로 다시 시작 |
| 루마니아 | 16팀 → 상6 플레이오프 · 하10 플레이아웃, 승점 절반 |
| 벨기에 | 16팀 30경기 → 상6 챔피언스 플레이오프, 승점 절반 |
| 이스라엘 · 키프로스 · 체코 · 핀란드 | 비슷하게 갈라요 |

여기서 핵심은 **승점 절반**이에요. 정규리그에서 벌어진 차이를 반으로 줄여서, 시즌 막판을 다시 팽팽하게 만들어 줘요.

### 4. 아페르투라 · 클라우수라 (한 해 두 시즌)

한 해를 반으로 나눠 우승팀을 두 번 뽑아요. 강등은 **두 시즌을 합산**하거나 여러 해 평균으로 정해요.

**멕시코 · 우루과이 · 파라과이 · 코스타리카 · 온두라스 · 과테말라**가 이렇게 해요.
콜롬비아·페루·에콰도르도 두 단계로 나눈 뒤 마지막에 플레이오프를 붙여요.

### 5. 플레이오프로 챔피언을 가려요

정규리그는 순위를 매기는 과정일 뿐이고, 진짜 우승은 상위 팀들이 토너먼트로 가려요.

**미국**(콘퍼런스 동·서 → 플레이오프) · **호주**(파이널 시리즈) · **인도** · **인도네시아** · 멕시코(리기야)가 그래요.
정규리그 1위에게는 서포터스 실드 같은 상을 따로 줘요.

### 6. 승격 플레이오프

2부 상위권끼리 토너먼트를 치러서 마지막 승격 한 장을 다퉈요. **잉글랜드**(3~6위) · **스페인** · **이탈리아** ·
**독일**(2부 3위 ↔ 1부 16위)이 대표적이에요.

### 7. 강등 없음

**미국 · 호주 · 인도 · 멕시코(현행)** 는 프랜차이즈 구조라 리그가 닫혀 있어요.
대신 드래프트나 샐러리캡 같은 다른 장치로 균형을 맞춰요.

## 게임에 넣은 순서

넣기 쉬운 것부터 차례로 넣었고, 그때마다 **세계가 얼마나 흔들리는지**도 같이 봤어요.

| | 할 일 | 건드린 곳 |
|---|---|---|
| ✅ | **① 리그마다 팀 수** | 평판 사다리를 길이에 맞춰 생성 · 도시 배분 · 시즌 길이 |
| ✅ | **② 나라별 승강 자리** | `NationNames.SwapPerTier` — 브라질 4팀, 벨기에 1팀 |
| ✅ | **③ 강등 없음** | ②에서 자리가 0 인 경우 — 미국 · 호주 · 인도 · 멕시코 |
| ✅ | **④ 승격 플레이오프** | `PromotionPlayoff` — 승격 PO(잉글랜드식)와 승강 PO(독일식) |
| ✅ | **⑤ 스플릿 + 승점 절반** | `LeagueSplit` — 정규 일정 뒤에 2차 일정을 이어 붙여요 |
| ✅ | **⑥ 플레이오프 챔피언** | `ChampionPlayoff` — 우승을 정하는 단계를 한 겹 떼어 냈어요 |
| ✅ | **⑦ 아페르투라/클라우수라** | `TwoStage` — 한 해 안에서 순위표를 둘로 나눠요 |

**일곱 가지 모두 들어가 있어요.** 아래는 넣으면서 고민했던 것들이에요(최근에 넣은 것부터).

### ⑦ 은 이렇게 넣었어요

처음에는 "시즌 경계 자체를 뜯어고쳐야 한다"고 적어 뒀었어요. 재계약·나이·재정이 전부 1년 단위로 도니까요.
**그런데 막상 들여다보니 그럴 필요가 없었어요.**

| | |
|---|---|
| **일정은 손대지 않았어요** | 리그 일정은 원래부터 전반기에 한 바퀴를 돌고, 후반기에 홈·원정을 뒤집어 한 바퀴를 더 돌아요. 멕시코 18팀이면 1~17라운드가 딱 한 바퀴, 18~34라운드가 또 한 바퀴예요. 대회를 둘로 만들려면 **어디서 끊어 셀지**만 정하면 됐어요. |
| **한 해는 그대로 한 시즌이에요** | 우승만 두 번 나오고, 계약 만료·나이·예산은 1년에 한 번만 돌아요. 실제로도 멕시코 선수가 한 해에 두 살씩 먹지는 않잖아요. |
| **강등은 한 해 합산으로** | 반년 못했다고 내려보내면 너무 가혹하고, 실제 규정도 두 대회를 합치거나 여러 해 평균을 써요. 대륙 대회 출전권과 구단 역대 성적도 합산으로 봐요. |
| **⑥ 과 맞물려요** | 멕시코는 두 대회가 **각각** 리기야로 끝나요. 실제로도 그렇거든요. 돌려 보니 아페르투라 2위가 리기야를 뚫고 우승하는 판도 나왔어요. |

순위표 화면에는 **아페르투라 · 클라우수라 · 한 해 합산** 세 가지를 다 뒀어요.
1위가 우승이 아닌 데다 순위표까지 둘이라, 설명이 없으면 버그로 보이기 딱 좋거든요.

손댄 곳은 `Standings`(단계별 집계) 하나와, 합산을 읽어야 하는 세 곳(승강 · 대륙 출전권 · 구단 역대 성적)뿐이에요.

### ⑥ 은 이렇게 넣었어요

정규리그가 끝나면 **상위 몇 팀이 다시 붙어서 우승을 가져가요.** 미국은 여덟 팀, 호주는 여섯, 인도는 넷이에요.

| | |
|---|---|
| **순위는 그대로 둬요** | 플레이오프 성적 때문에 순위가 내려가지는 않아요. 승강은 정규리그 순위대로 해요(애초에 이 나라들은 대개 강등이 없어요, ③). |
| **대진은 ④와 같은 기계를 써요** | `Knockout` 하나를 둘이 같이 써요 — 씨드 순서, 부전승, 준결승 두 경기·결승 한 판, 합산이 같으면 순위 높은 쪽. 다른 건 씨드 열쇠뿐이라 같은 해에 대진 두 개를 치러도 결과가 겹치지 않아요. |
| **우승팀을 묻는 길은 하나예요** | `ChampionPlayoff.ChampionOf(season)` 이에요. 순위표 1위를 바로 읽으면 이 나라들에서는 틀려요. 기록이 없는 시즌(예전 세이브·유럽 리그)은 1위를 돌려줘요. |
| **우승은 리그에 적어 둬요** | 플레이오프는 시즌이 넘어가는 바로 그 순간에 치러지는데, 그때 순위표는 통째로 새것이 돼요. `LeagueData.lastChampionClubId` 에 적어 두지 않으면 화면이 "누가 우승했지?"를 영영 알 수 없어요. |

순위표에는 **진출 경계선**과 한 줄 설명을 그려 뒀어요. 1위가 우승이 아니라는 걸 모르면 버그로 보이니까요.

여덟 시즌을 돌려 보니 미국 1부는 여덟 번 중 두 번, 멕시코 2부는 무려 **일곱 번**이나 정규리그 1위가 우승을 놓쳤어요.
참가 팀이 많을수록 1위의 이점이 옅어지더라고요.

### ⑤ 는 이렇게 넣었어요

정규리그를 다 치른 순간 순위표를 보고 두 조로 가른 다음, **그 자리에서 2차 일정을 만들어 이어 붙여요.**
스코틀랜드 1부는 22라운드를 치른 뒤 여섯 팀씩 갈려 다섯 경기를 더 치르니까 27라운드가 돼요.

| | |
|---|---|
| **조 경계가 승점보다 먼저예요** | 하위 조 1위가 상위 조 꼴찌보다 승점이 많아도 위로 올라갈 수 없어요. 순위표를 정렬할 때 조를 가장 먼저 봐요. |
| **승점 절반** | 오스트리아·스위스·루마니아·벨기에는 갈릴 때 승점이 절반(올림)이 돼요. 순위표는 매번 경기 기록에서 다시 세기 때문에, 줄어든 몫을 `pointsCarry` 에 따로 적어 둬요. |
| **상위 조는 리그의 절반이에요** | 두 조가 더 치르는 경기 수가 같아야 억울한 쪽이 없어요. 실제로는 벨기에처럼 상위 6·하위 10 으로 갈리는 나라도 있긴 해요. |
| **홈 횟수를 이어받아요** | 정규리그에서 원정이 많았던 팀이 2차 일정에서 홈을 먼저 받아요. 경기 수가 적어서 한쪽으로 몰리면 그대로 억울해지거든요. |

순위표에는 경계선도 그려 뒀어요. 승점만 보면 순서가 뒤집혀 보이니, 선과 한 줄 설명이 없으면 버그처럼 보여요.

### ④ 는 이렇게 넣었어요

두 가지 모양을 다 넣었어요.

| 모양 | 어떻게 | 나라 |
|---|---|---|
| **승격 플레이오프** | 아래 리그 상위권끼리 토너먼트를 해요. 자동 승격은 `자리 - 1` 이고, 우승팀이 마지막 한 장을 가져가요. | 잉글랜드 4팀 · 이탈리아 6팀 · 스페인 · 튀르키예 · 스코틀랜드 · 폴란드 … |
| **승강 플레이오프** | 내려갈 뻔한 위 리그 팀과 올라올 뻔한 아래 리그 팀이 직접 맞붙어요. 아래 팀이 이긴 해에만 오가는 팀이 하나 늘어요. | 독일 · 프랑스 · 네덜란드 · 한국 · 스위스 · 오스트리아 · 덴마크 … |

- 준결승까지는 홈·원정 두 경기, 결승은 한 판이에요.
- 참가 팀 수가 2의 거듭제곱이 아니면 **위 씨드가 부전승**으로 올라가요(여섯 팀이면 1·2위가 준결승부터).
  1위와 2위는 결승에서야 만나요.
- 합산이 같으면 **정규리그 순위가 높은 쪽**이 올라가요. 실제로는 연장·승부차기까지 가지만,
  한 시즌을 더 잘 치른 팀에게 이점을 주는 규정 자체는 흔해요.
- 결과는 받은 소식에 대진째로 남겨요. 순위표만 봐서는 왜 그 팀이 올라갔는지 알 수 없으니까요.

> **이제 내 플레이오프 경기는 직접 뛸 수 있어요.** 내 구단이 플레이오프에 걸리면 시즌 넘김이 내 경기 앞에서
> 잠깐 멈추고, 경기 화면에서 직접 치르거나 바로 결과를 볼 수 있어요. 시즌 넘김은 "치른 경기의 점수"만 적어 두고
> 이어 붙일 때 대진을 처음부터 다시 걸어요 — 적어 둔 경기는 다시 치르지 않으니 기록이 두 번 쌓이지 않아요
> (`RolloverState`). 그래서 멈추지 않고 넘긴 세계와 멈췄다가 '바로 결과 보기'로 넘긴 세계가 한 바이트도 다르지 않아요.
> 승격 플레이오프(잉글랜드식) · 승강 플레이오프(독일식) · 챔피언 결정전(미국식) 모두 돼요.
> 아페르투라(⑦)처럼 시즌 중간에 치르는 챔피언 결정전은 아직 자동으로 돌아가요.

### 팀 수가 달라지자 드러난 것

리그마다 라운드 수가 달라지면서 **진행 엔진의 전제 하나가 깨졌어요.** `PlayNextRound` 가 *내 경기*를 기준으로
세계를 돌리고 있었거든요. 그러다 보니

- 홀수 팀 리그에서 **내가 쉬는 주**(부전승)의 라운드를 어느 리그도 치르지 않았고,
- 내 리그가 먼저 끝나면(1부 38 · 2부 46) 2부의 남은 라운드가 그냥 사라졌어요.

지금은 **세계가 아직 치르지 않은 가장 이른 라운드**를 기준으로 돌고, 승강을 처리하기 전에
`SeasonRollover.FinishRemainingFixtures` 로 남은 경기를 전부 치러요.

> **팀 수가 달라도 한 세계에서 같이 돌아가요.** 진행 엔진이 라운드 번호로 돌기 때문에, 36라운드짜리 리그와
> 46라운드짜리 리그가 섞여 있어도 각자 자기 일정을 치러요. 다만 리그가 먼저 끝난 나라의 구단은 남은 라운드 동안
> 컵만 치러요.
