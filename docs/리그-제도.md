# 리그 제도

**리그의 모양은 그 나라의 성격입니다.** 스무 팀이 서른여덟 경기를 치르는 것이 축구의
기본값처럼 보이지만, 실제로는 그런 리그가 오히려 소수입니다. 스코틀랜드는 열두 팀이
서른세 경기를 치르고 상·하위로 갈라지고, 멕시코는 한 해에 두 번 우승팀을 뽑고,
미국은 강등이 없는 대신 플레이오프로 챔피언을 가립니다.

이 문서는 **무엇이 실제인지**를 먼저 적고, 그중 무엇을 게임에 넣을 수 있는지를 적습니다.
수치는 최근 시즌 기준이고 해마다 조금씩 바뀝니다 — 그대로 베끼는 것이 목적이 아니라
**나라마다 다르게 느껴지게** 하는 것이 목적입니다.

## 지금 엔진이 하는 것

| | |
|---|---|
| 리그당 팀 수 | **20팀 고정** — 실제와 가장 크게 어긋나는 자리 |
| 경기 수 | 더블 라운드로빈 38경기 |
| 승강 | 위아래 **3팀 고정** |
| 우승 | 정규리그 1위 |
| 시즌 | 한 해에 한 번 |

일정 생성기(`FixtureScheduler.Build`)는 **이미 팀 수를 가리지 않습니다** — 홀수면 부전승
자리를 넣고 `n-1` 라운드로 짭니다. 진행 엔진도 라운드 번호로 돌기 때문에 라운드 수가
다른 리그가 한 세계에 섞여도 됩니다.

묶여 있는 곳은 셋뿐입니다.

1. `WorldGenerator.ClubsPerLeague = 20` — 도시 배분, 리그 생성 루프, 시즌 길이
2. `RepLadder` 세 묶음 — 길이가 20으로 고정된 평판 사다리
3. `league.promotionSpots / relegationSpots` — 전부 3

## 나라마다의 실제 제도

### 1부 팀 수

| 팀 | 나라 |
|---|---|
| 10 | 크로아티아 · 아일랜드 · 뉴질랜드 (네 번씩 맞붙어 36경기) |
| 12 | 스코틀랜드 · 오스트리아 · 스위스 · 덴마크 · 헝가리 · 아이슬란드 · 핀란드 · 한국 · 카타르 · 코스타리카 · 파라과이 |
| 13~14 | 호주 · 인도 · 그리스 · 이스라엘 · 키프로스 · 베트남 · UAE · 베네수엘라 |
| 16 | 벨기에 · 러시아 · 우크라이나 · 체코 · 세르비아 · 루마니아 · 스웨덴 · 노르웨이 · 중국 · 이란 · 태국 · 모로코 · 튀니지 · 알제리 · 남아프리카 · 우루과이 · 칠레 · 볼리비아 |
| 18 | 독일 · 프랑스 · 포르투갈 · 네덜란드 · 폴란드 · 멕시코 · 사우디아라비아 · 인도네시아 · 이집트 · 가나 |
| 20 | 잉글랜드 · 스페인 · 이탈리아 · 브라질 · 일본 · 콜롬비아 · 나이지리아 · 튀르키예 |
| 24+ | 미국(29·콘퍼런스) · 아르헨티나(28) |

### 2부가 1부보다 큰 나라

잉글랜드 2·3·4부는 **24팀**입니다(46경기). 스페인 2부는 22팀, 이탈리아 2부는 20팀.
"아래로 갈수록 팀이 많아진다"는 것 자체가 피라미드의 성격입니다.

### 승강 자리

| 자리 | 나라 |
|---|---|
| 4팀 | 브라질 |
| 3팀 | 잉글랜드 · 스페인 · 이탈리아 · 튀르키예 · 일본 · 사우디아라비아 · 태국 |
| 2팀 + 플레이오프 | 독일(16위가 2부 3위와 홈앤드어웨이) |
| 2팀 | 포르투갈 · 네덜란드 · 러시아 · 일본 |
| 1~2팀 | 작은 리그 대부분 |
| **없음** | 미국 · 호주 · 인도 · 멕시코(현행) |

2부에서 올라가는 자리도 다릅니다. 잉글랜드 2부는 **1·2위 자동 승격 + 3~6위 플레이오프**로
한 장을 더 줍니다. 스페인·이탈리아·독일 2부도 비슷한 플레이오프가 있습니다.

## 제도의 일곱 갈래

실제 리그를 모양으로 묶으면 일곱 가지입니다.

### 1. 더블 라운드로빈 (기본)

모두와 홈·원정 한 번씩. 잉글랜드·스페인·이탈리아·독일·일본 등 대부분.

### 2. 쿼드러플 라운드로빈

팀이 열뿐이라 네 번씩 맞붙어 36경기. **크로아티아 · 아일랜드 · 뉴질랜드**.

### 3. 스플릿 (정규리그 뒤 상·하위 분리)

정규리그를 치른 뒤 상위권과 하위권으로 갈라 자기들끼리 더 치릅니다. 상위 그룹에서만
우승이 나오고, 하위 그룹에서만 강등이 나옵니다.

| 나라 | 모양 |
|---|---|
| 스코틀랜드 | 12팀 33경기 → 상6·하6 각 5경기 (38경기) |
| 한국 | 12팀 33경기 → 파이널A·B 각 5경기 |
| 덴마크 | 12팀 22경기 → 챔피언십 6팀 10경기 + 강등권 |
| 오스트리아 · 스위스 | 12팀 → 상·하위 분리, **승점 절반**으로 시작 |
| 루마니아 | 16팀 → 상6 플레이오프 · 하10 플레이아웃, 승점 절반 |
| 벨기에 | 16팀 30경기 → 상6 챔피언스 플레이오프, 승점 절반 |
| 이스라엘 · 키프로스 · 체코 · 핀란드 | 비슷한 분리 |

**승점 절반**이 핵심 장치입니다. 정규리그에서 벌린 차이를 반으로 줄여 막판을 다시
팽팽하게 만듭니다.

### 4. 아페르투라 · 클라우수라 (한 해 두 시즌)

한 해를 둘로 갈라 각각 우승팀을 뽑습니다. 강등은 **두 시즌 합산**(또는 여러 해 평균)으로
정합니다.

**멕시코 · 우루과이 · 파라과이 · 코스타리카 · 온두라스 · 과테말라**.
콜롬비아·페루·에콰도르도 두 단계로 나누고 마지막에 플레이오프를 붙입니다.

### 5. 플레이오프로 챔피언을 가린다

정규리그는 순위를 매기는 과정일 뿐이고, 상위 팀들이 토너먼트로 우승을 가립니다.

**미국**(콘퍼런스 동·서 → 플레이오프) · **호주**(파이널 시리즈) · **인도** ·
**인도네시아** · 멕시코(리기야). 정규리그 1위에게는 따로 상(서포터스 실드 등)을 줍니다.

### 6. 승격 플레이오프

2부 상위권이 토너먼트로 마지막 승격 한 장을 다툽니다. **잉글랜드**(3~6위) ·
**스페인** · **이탈리아** · **독일**(2부 3위 ↔ 1부 16위).

### 7. 강등 없음

**미국 · 호주 · 인도 · 멕시코(현행)**. 프랜차이즈 구조라 리그가 닫혀 있습니다.
대신 드래프트·샐러리캡 같은 다른 장치가 균형을 맞춥니다.

## 게임에 넣는 순서

넣기 쉬운 것부터, 그리고 **세계가 흔들리는 정도**를 같이 적습니다.

| | 할 일 | 건드리는 곳 |
|---|---|---|
| ✅ | **① 리그마다 팀 수** | 평판 사다리를 길이에 맞춰 생성 · 도시 배분 · 시즌 길이 |
| ✅ | **② 승강 자리 나라별** | `NationNames.SwapPerTier` — 브라질 4팀, 벨기에 1팀 |
| ✅ | **③ 강등 없음** | ②의 특수한 경우(0) — 미국 · 호주 · 인도 · 멕시코 |
| | ④ 승격 플레이오프 | 시즌 끝에 작은 토너먼트 하나 |
| | ⑤ 스플릿 + 승점 절반 | 정규 일정 뒤에 2차 일정을 덧붙이는 구조 |
| | ⑥ 플레이오프 챔피언 | 우승팀을 정하는 자리를 한 겹 분리 |
| | ⑦ 아페르투라/클라우수라 | 한 해에 시즌을 두 번 — 시즌 경계 자체를 손봐야 함 |

④~⑥은 시즌 끝 처리에 단계를 더하는 일입니다. ⑦은 "시즌 = 1년"이라는 전제를 깨므로
가장 큽니다 — 재계약·나이·재정이 전부 연 단위로 돌고 있습니다.

### 팀 수가 달라지자 드러난 것

리그마다 라운드 수가 달라지면서 **진행 엔진의 전제 하나가 깨졌습니다.**
`PlayNextRound` 가 *내 경기*를 기준으로 세계를 돌리고 있었는데, 그러면

- 홀수 팀 리그에서 **내가 쉬는 주**(부전승)의 라운드를 어느 리그도 치르지 않고,
- 내 리그가 먼저 끝나면(1부 38 · 2부 46) 2부의 남은 라운드가 사라집니다.

지금은 **세계가 아직 치르지 않은 가장 이른 라운드**를 기준으로 돌고, 승강을 처리하기
전에 `SeasonRollover.FinishRemainingFixtures` 로 남은 경기를 전부 치릅니다.

> **팀 수가 달라도 한 세계에서 같이 돕니다.** 진행 엔진이 라운드 번호로 돌기 때문에,
> 36라운드짜리 리그와 46라운드짜리 리그가 섞여도 각자 자기 일정을 치릅니다.
> 다만 리그가 끝난 나라의 구단은 남은 라운드 동안 컵만 치릅니다.
