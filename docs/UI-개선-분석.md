## 1. FM 18개 화면 한눈에 보기 — 배치와 표현

| 화면 | 덩어리 배치 | 정보를 보여 주는 방식 | 더 들어가는 길 |
|---|---|---|---|
| 홈 | 위 3칸 (다음 경기, 일정, 뉴스) + 아래 3열 (순위, 탭 패널, 선수·팀 기록) | 엠블럼, 승무패 색 동그라미, 폼 미니 막대, 순위를 말로 ("6위") | 패널 제목 `>`, 패널 `▾` 로 위젯 바꾸기 |
| 수신함 | **마스터-디테일** (왼쪽 목록, 오른쪽 본문) | 날짜별 묶음, 보낸 사람 + 시간, 답장이 필요하면 아이콘 | 본문 아래 행동 버튼 ("기자회견 >") |
| 선수단 | 툴바 + 포지션 칩 + 화면 가득한 표 | 색 알약 포지션, ★, 미니 폼 막대 | 이름 → 프로필, 행 우클릭 행동 메뉴, **View 바꾸기** |
| 선수단 계획표 | **피치가 곧 필터** (왼쪽) + 그 포지션 선수 목록 (오른쪽) + 아래 카드 3장 | 포지션별 ★ 평균 | 피치 칸 클릭 → 목록 필터 |
| 세력 구도 | 위 카드 3장 (결속력, 분위기, 감독 지지) + 아래 목록 | 막대 + **등급 단어**("우수") + 👍 근거 문장 | 계층 탭은 **피라미드**, 만족도 탭은 **색 히트맵 + 이모지** |
| 전술 | 왼쪽 (전술 성향, 팀 지시 카드 3장) / 가운데 (피치) / 오른쪽 (선수 표) | 역할-임무 색 알약, 숙련도 막대 | "변경" → 피치 위에 패널이 겹쳐 열려요 |
| 데이터 허브 | 레이더 차트 + 요약 글 + 번호 붙은 발견점 / 오른쪽 보고서 타임라인 | **레이더 (우리 vs 리그 평균)** | 팀 성적 >, 선수 성적 > |
| 스탭 | 부서별 3열 (코칭, 스카우트, 의료) | 사람 아이콘 줄, 자리 채움 "1/1", 리그 최고·최저선이 그어진 막대 | 직원 이름, U21·U18 스탭 > |
| 훈련 | **주간 달력 격자** (요일 × 세션) + 아래 카드 3장 | 색 블록 + 아이콘, 요일별 강도 막대 | 블록 → 세션 상세 |
| 의료 센터 | 조언 배너 + 위험 평가 표 + 아래 (부상, 복귀) | 등급 단어에 색 ("과중함", "매우 낮음"), 몸 실루엣, 빨간 위험 칸 | 선수 이름 |
| 주요 일정 | **마스터-디테일** (왼쪽 일정 표, 오른쪽 경기 상세) | 대회별 행 색, 월 구분선, 결과 점 | 경기 → 라인업·평점 → 경기 보기 |
| 대회 | 대회별 카드 격자 | 운영진 기대 vs 성과 막대 | 카드마다 [팀 기록 >][선수 평점 >][규칙 >] |
| 스카우트 | 위 KPI 띠 + 왼쪽 (영입 집중 목록, 지도) + 오른쪽 (추천 표) | **추천 등급 글자 동그라미 (A-, B+)**, 미니 피치 포지션 아이콘 | 이름, 집중 항목 > 편집 × |
| 이적 | KPI 띠 + 부대 조항 칩 + 활동 표 (전체/영입/방출) | 금액, 상태 | 담당자, 스카우트 센터 > |
| 구단 정보 | 4열 대시보드 (세부 정보, 핵심 인물, 최근 경기·전술, 명예의 전당) | 등급 단어 + ★, 트로피 수, A+ 동그라미 | 급료 >, 재정 > |
| 구단 비전 | 목표 표 + 시즌별 탭 / 오른쪽 운영진 평가 | 중요도 막대 + 단어, **상태 알약** (진행 중·기쁨·판단 보류) | 운영진에게 요청 ▾ |
| 재정 | 큰 면적 그래프 4개 + 오른쪽 예산 | **시계열 면적 그래프**, 손익 0선 위아래 | 예산 조정 ▾ |
| 육성 센터 | 위 요약 3칸 + 주목할 선수 목록 | 성장 스파크라인 + 코치 조언 말풍선 | U21·U18 > |

**모든 화면에 공통으로 있는 틀**
- 왼쪽에 고정된 메뉴
- 화면마다 위쪽에 탭 띠가 있고, `▾` 가 붙은 탭은 하위 페이지와 행동을 같이 담고 있어요
- 타이틀 바: ← → 뒤로·앞으로, ▲▼ 같은 목록에서 이전·다음, 검색, 화면 제목 + 한 줄 부제
- 상태를 알려 주는 진행 버튼: 처리할 일이 있으면 빨간 "답변 요망"으로 바뀌면서 진행을 막아요

## 2. 우리 게임의 지금 UI — 코드로 본 진단

### 지금 있는 것
- 레이아웃 `FT.App/Layout/MainLayout.razor`
  - 왼쪽 사이드바: 메뉴 4묶음 17개, 그리고 **상태 배지**(이적 요청·불만·만료 임박 수·창구 열림·컵 생존·기자회견 대기·안 읽은 수)
  - 위쪽 바: 날짜, 다음 경기, 이사회 배지, 저장, **상황에 따라 바뀌는 진행 버튼**(경기 진행 / 한 주 넘기기 / 다음 시즌 시작)
- 페이지마다 틀이 같아요: `h1` + 회색 부제 + `card` 묶음. 정보는 `stat` 타일, `ft` 표, `bar` 막대로 보여 줘요
- 표기 규칙은 `FT.App/Components/Ui.cs` 한 곳에 모여 있어요 (포지션 색, 금액, 사기 단어 등)

### 잘 된 것 — 그대로 두기
| 항목 | 왜 좋은가요 |
|---|---|
| 협상 테이블 `Components/ContractTable.razor` | 항목마다 **상대 요구 / 내 제안 / 모자람·충분·넉넉함 배지**가 붙고, 슬라이더를 움직이면 바로 다시 계산돼요. **이 부분은 FM 보다 투명해요** (FM 은 약속 단계에서 항목별 반응 없이 전체 게이지만 있어요) |
| 전술 지시 옆의 trade-off 문장 (`Pages/Tactics.razor` 의 `trade`) | "공을 더 쥐지만 다리가 더 빨리 지칩니다" 같은 대가 설명은 FM 에 없어요. 배우는 사람에게 큰 장점이에요 |
| 메뉴 배지 | FM 의 "처리할 일" 신호와 같은 역할을 벌써 하고 있어요 |
| 진행 버튼 분기 | FM 의 상황별 진행 버튼과 같은 생각이에요 |
| `Ui.cs` 한 곳에 모은 표기 | 표현을 바꿀 때 한 군데만 고치면 돼요. 아래 개선안들의 발판이에요 |

### 끊긴 길 — 불편하다고 느낀 곳이 실제로 어디인지
1. **구단 페이지가 없어요.** 라우트 목록에 `/club/{id}` 가 없고, 구단 이름은 어디에서도 링크가 아니에요 (순위표, 일정, 대시보드 다음 경기 모두 글자만 있어요)
2. **선수 화면에서 할 수 있는 게 없어요.** `Pages/PlayerPage.razor` 의 버튼은 맨 아래 "스쿼드로 돌아가기" 하나뿐이에요
   - 재계약하려면 계약 메뉴로 가서 표에서 그 선수를 다시 찾아야 해요
   - 이적이나 임대도 각자 메뉴로 따로 가야 해요
   - FM 은 같은 행동을 선수 프로필의 탭 ▾ 와 스쿼드 행 우클릭, 두 곳에서 다 열어 줘요
3. **받은 소식이 막다른 길이에요.** `InboxItem`(`FT.Core/World/GameWorld.cs:298`)은 날짜·제목·본문·종류·읽음만 갖고 있어서, "부상"이나 "이적 요청" 소식을 눌러도 그 선수나 화면으로 갈 수 없어요
4. **스쿼드 행에는 '열기' 하나뿐이에요.** 행을 누르면 프로필로 가는 게 전부라, 행에서 바로 할 수 있는 행동이 없어요
5. **카드 → 전체 화면 링크가 일부에만 있어요.** 대시보드의 순위표·받은 소식·주목할 선수에는 "전체 보기"가 있는데, 다음 경기 상대·이사회 목표에는 없어요

### 정보가 듬성듬성한 곳
| 화면 | 지금 | FM 과 비교하면 |
|---|---|---|
| 선수 | 카드가 세로로 쌓여요. 능력치 카드 2장 (기술 11 / 신체 7 + 정신 11), 행마다 이름 + 막대 + 숫자라서 스크롤이 길어요 | FM 은 3열 36개 + 정보 기둥이 한 화면에 다 들어가요 |
| 스쿼드 | 열 14개 고정, 정렬은 `<select>` | FM 은 View 16종 이상, 머리글 클릭 정렬, 포지션 칩 필터 |
| 대시보드 | 위 stat 4개 + 카드 5개 | FM 홈은 일정·기록·상대 분석까지 한 화면에 담아요 |
| 받은 소식 | 한 줄 목록 | FM 은 마스터-디테일 + 행동 버튼 |

## 3. 적용안 — 그대로 / 고쳐서 / 가져오지 않기

### A. 그대로 가져올 것 (구조가 단순하고 효과가 커요)
1. **이름 링크 컴포넌트**: `<PlayerLink>`, `<ClubLink>`
   - 이름이 나오는 모든 곳에서 이 컴포넌트를 쓰게 해요. `Ui.cs` 처럼 규칙은 한 곳에서 정하고요
2. **카드 제목을 링크로**: `card-head` 의 `h3` 를 누르면 해당 전체 화면으로 가요. "전체 보기" 버튼은 없애도 되고 남겨도 돼요
3. **순위를 말로 같이 쓰기**: "득점 21 (리그 1위)", "실점 6 (6위)" 처럼요. 이미 계산할 수 있는 값이 많아요
4. **목록 안에서 이전/다음**: 선수 화면 위쪽에 ◀ ▶ 를 두고 스쿼드 순서대로 넘겨 봐요
